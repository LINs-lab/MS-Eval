Execution Paradigms

Same task, same evaluator. Single-Agent is the base. MAD-SAE inherits its boundary and completion rule; each mode then adds only its roster and orchestration constraint.

Task

arxiv-survey-presentation

Prepare an NLP / LLM-reasoning survey: read the local methodology guide and freeze comparison criteria; retrieve five recent arXiv papers and extract LaTeX-backed method, dataset, finding, and section counts; then write Survey_Data.xlsx (three literal sheets, one writer) and NLP_Survey.pptx (at least six slides, one writer).

Task-Solving Rationale with Sub-Task Decomposition (TRSD)

annotated oracle plan

The main agent first freezes the schema and verifies source capability. It then delegates Wave 1: two parallel explore sub-agents — one returns the methodology packet, the other the candidate manifest — and freezes one distinct paper per row. Wave 2: five parallel explore sub-agents, one paper each, return compact records. After computing the taxonomy and statistics once, the main agent delegates Wave 3: two parallel coder sub-agents with exclusive file ownership — Survey_Data.xlsx and NLP_Survey.pptx — then reconciles both files and claims done.

Principles — inherited substrate, then mode-specific add-ons

Shared by every arm · from Single-Agent p_sys
  • Core. Solve the task with granted tools; realize every artifact and side effect. One-step work stays on the main agent; independent calls may ship as a native bundle.
  • Visible boundary. Workspace + task tools only. No harness / evaluator / ground-truth probing. Do not repair infrastructure.
  • Completion. A written “done” is not done. Only claim_done ends the episode, and it ends it instantly.

Single-Agent — keeps the substrate as-is

  • Empty roster; no Agent / AgentSwarm
  • Parallelism = native tool bundle only
  • One context window

MAD-SAE — inherits boundary + completion, then adds

  • Only main may claim_done
  • Delegate iff multi-step and independently verifiable
  • Self-contained prompt; reuse returned facts / paths / IDs
  • Read-only roles cannot write
  • Heterogeneous ∥ → concurrent Agent; homogeneous batch → AgentSwarm

Sub-agent principles — isolated workers under the main agent

Every sub-agent inherits the visible boundary, runs in an isolated context (the assignment must be self-contained), and is forbidden to call claim_done or to nest Agent / AgentSwarm. Read-only roles cannot mutate state.

Coarse roster · Auto (Gen), Plan-1st, Oracle

plan — read-only. Ordered decomposition and validation; never write.
explore — read-only. Gather evidence; return structured findings.
coder — writable. Execute a scoped artifact / side-effect; return paths and IDs.

Specialist roster · Auto (Spec) keeps plan, replaces explore / coder

plan — same as coarse.
academic-literature-researcher — RO. Papers, sections, scholarly metadata.
web-domain-researcher — RO. Pages, APIs, recipes, rail, video / transcript.
enterprise-data-analyst — RO. Canvas, Snowflake, WooCommerce, supplied docs.
financial-market-analyst — RO. Prices, statements, finance news.
office-report-builder — RW. Local Excel / Word / PPT / PDF / datasets.
external-workflow-operator — RW. Email, calendar, forms, cloud sheets, Notion.
