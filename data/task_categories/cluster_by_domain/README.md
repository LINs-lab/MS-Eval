[domain-cases.tsv](domain-cases.tsv) assigns each of the 166 tasks to one domain. Each domain directory contains a task-ID list and a README linking to canonical task documents. These categories support dataset statistics and sliced analysis for both DA and OU; they are distinct from sub-agent functional read labels.
