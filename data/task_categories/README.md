# Task categories

This directory groups the benchmark tasks along two dimensions: application domain and delegation need. Each category contains task-ID lists and relative links to the canonical task documents.

| Directory | Scope |
| --- | --- |
| [cluster_by_delegation](cluster_by_delegation/README.md) | Curated delegation-need and read/write task categories |
| [cluster_by_domain](cluster_by_domain/README.md) | One benchmark domain per task, shared across analyses |

All categories refer to the canonical documents in [oracle166](../oracle166/README.md). Golden units and cached functional labels are bundled with the [DA evaluator](../../eval/delegation_appropriateness/README.md). The price table is bundled with the [OU evaluator](../../eval/orchestration_utilities/README.md).
